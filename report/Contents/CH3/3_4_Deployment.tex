\subsection{Nền tảng Triển khai}
\label{sec:3_5}

Hệ thống được đóng gói và vận hành trên môi trường điện toán đám mây hiện đại, hướng tới tính sẵn sàng và tính di động cao:
\begin{itemize}
    \item \textbf{Docker \& Docker Hub:} Mã nguồn Backend và AI-Core được "đóng gói" thành các Container độc lập với đầy đủ môi trường chạy (Runtime, Dependencies) thông qua các file cấu hình \texttt{Dockerfile}. Các bộ ảnh (Image) này được lưu trữ trên Docker Hub để sẵn sàng cho quy trình pull/push ở mọi nền tảng.
    \item \textbf{Microsoft Azure App Service:} Nền tảng PaaS (Platform as a Service) của Azure được chọn để chạy các Docker Container backend. Đề tài sử dụng cấu hình \textbf{Basic B2} với khả năng quản lý tài nguyên linh hoạt, giúp duy trì API ổn định trong môi trường Production.
    \item \textbf{Vercel:} Nền tảng chuyên biệt được sử dụng để triển khai phân hệ Frontend (React). Vercel tích hợp Vercel CLI, tự động tối ưu hóa tài nguyên tĩnh và phân phối nội dung thông qua mạng CDN toàn cầu, đảm bảo ứng dụng Frontend truy cập nhanh ở mọi vị trí địa lý.
\end{itemize}
